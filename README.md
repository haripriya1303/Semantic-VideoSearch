# Semantic Audio Search

Semantic Audio Search is a web application that enables users to search audio and podcast content using natural language queries.

## Features

- Upload audio files
- Download audio from supported links
- Speech-to-text transcription
- Semantic search
- Timestamp-based playback
- Free and open-source stack

## Tech Stack

- FastAPI
- React
- Faster-Whisper
- FAISS
- Sentence Transformers
- yt-dlp
